# PersonalMemory

PersonalMemory 是一个面向个人的、本地优先的 AI 记忆工作台，基于
[TencentDB-Agent-Memory](https://github.com/TencentCloud/TencentDB-Agent-Memory)
进行二次开发。

它帮助个人在不同 AI Agent、项目和会话之间持续积累并复用：

- 偏好、事实、决定与上下文；
- 已验证的工作流程和技能；
- 个人文档知识；
- 项目代码知识。

## 产品定位

上游正在向团队级 Memory Hub 演进；PersonalMemory 聚焦单用户场景：部署简单、默认私密、可审阅、可纠错、可追溯、可迁移。

核心原则：

1. 本地优先，用户拥有原始数据和导出能力。
2. 默认私密，任何外发、共享或云端模型处理都需明确配置。
3. 记忆可见、可改、可删，并能追溯到原始证据。
4. 渐进披露，优先注入少量高价值信息，按需下钻。
5. 上游兼容，定期同步安全修复和通用能力，差异化功能保持模块化。
6. 安装简单，正式版本以一条命令完成安装、初始化和启动为目标。

## 项目名称

`PersonalMemory` 适合作为当前工程名和 MVP 名称：直观、与团队版定位形成区分，也便于理解。

它不适合作为最终商业品牌名：名称较通用，搜索辨识度和商标独占性弱，也容易被理解为普通个人笔记或操作系统内存工具。正式发布前应完成域名、GitHub、软件商标和应用商店重名检索，再决定是否采用独特品牌名，并保留 `Personal Memory` 作为品类副标题。
