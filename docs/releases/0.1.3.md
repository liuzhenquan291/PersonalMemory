# PersonalMemory 0.1.3 发布说明草案

仓库：`liuzhenquan291/PersonalMemory`。状态：待正式发布；不是已发布公告。

## 本次修复

备份或恢复完成后的自动重启现在沿用安装回执中的三项服务端口。操作失败后的恢复启动也沿用原端口，避免默认端口被其他服务占用时无法恢复服务。已有 0.1.1、0.1.2 标签保持不变。

同时修复 HTTP 80 端口解析、升级端口保留，以及多实例场景数据操作误检查默认端口。

同时同步实施状态、名称与渠道初查、MVP 后续待办。当前工程名存在同名/近似项目，不代表最终品牌或商标清查通过。

## 安装与兼容

- 支持矩阵仍为 macOS arm64、Linux arm64；需要 Node.js 22.19.0 及以上与 npm。
- 不新增 schema、不改变用户记忆、采集授权或模型授权语义。
- 仅按固定 `personalmemory-v0.1.3` tag 或同版源码包安装；核验状态见 [M5.11](../implementation-records/M5.11.md)。
- 源码资产：`PersonalMemory-0.1.3-source.tar.gz` 与独立 `.sha256`。
- 已有安装的升级前先完成并验证备份；完整使用说明以 [README](../../README.md) 为准。

默认零外联，模型配置需独立授权；新 L1 审批后才自动召回。完整 L2/L3 来源链、可读导入/索引重建、桌面自动更新、Windows/x64 与多设备同步仍是后续待办。
