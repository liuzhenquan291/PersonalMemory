# ADR-0004：MVP 只交付 Chat Memory

- 状态：accepted
- 决定日期：2026-08-07
- 负责人：PersonalMemory maintainers

## 决定

MVP 只覆盖对话记忆闭环。L0/L1 提供完整管理；L2/L3 首版提供查看和来源追溯，复杂结构化编辑后置。Skill、Wiki、CodeGraph 不进入 MVP 退出标准。

## 原因与替代方案

先把捕获、提炼、召回、纠错、导出和删除做成可信产品，能减少同时验证多个事实模型的风险。一次性交付全部资产类型会稀释隐私、恢复和安装质量。

## 后果与复议触发

M2-M3 的数据模型必须允许未来扩展，但不得提前加入未验证抽象。只有真实用户需求证明某一资产类型是完成 Chat Memory 闭环的阻断项时，才复议。
