# ADR-0002：模型可配置且默认零外联

- 状态：accepted
- 决定日期：2026-08-07
- 负责人：PersonalMemory maintainers

## 决定

无模型和 embedding 密钥时产品必须可安全启动、浏览和管理已有记忆；模型、embedding、遥测和云存储默认禁用。启用远端 provider 前必须向用户展示 provider、目标地址、用途和发送字段。本地 OpenAI-compatible provider 与远端 provider 使用同一接口，但信任提示不同。

## 原因与替代方案

个人记忆具有高敏感性，隐式使用默认公网 URL 不符合“默认私密”。默认绑定远端模型体验更快但不可接受；强制本地模型会提高安装门槛和硬件要求，因此采用可配置策略。

## 后果与复议触发

无模型时 L1-L3 自动提炼可以暂停，但 L0 和人工管理不能失效。M1.2 必须加入网络隔离证明。只有在离线模型成为可靠、轻量且跨平台的内置组件时，才重新评估默认 provider。
