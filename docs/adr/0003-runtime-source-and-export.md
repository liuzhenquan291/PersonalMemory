# ADR-0003：运行时数据库权威、可读导出可重建

- 状态：accepted
- 决定日期：2026-08-07
- 负责人：PersonalMemory maintainers

## 决定

SQLite 是本地运行时事务和查询的权威状态；用户拥有版本化、可读、带 manifest 与校验和的完整导出。FTS/向量索引必须可由规范化数据重建。当前 JSONL/Markdown 资产作为迁移输入和可读证据保留，但在重建格式冻结前不宣称它们单独构成完整事实源。

## 原因与替代方案

数据库权威能提供事务、一致查询和迁移；可读导出保证可迁移与避免锁定。纯文件事实源更透明，但并发更新、删除和索引一致性复杂；纯数据库则难以人工审阅和长期迁移。

## 后果与复议触发

所有 schema 变更都必须带迁移和旧版本 fixture；导出/恢复需要闭环验证。若后续证明文件优先模型能在事务、性能、删除和冲突合并上达到同等可靠性，可通过新 ADR 替代。
