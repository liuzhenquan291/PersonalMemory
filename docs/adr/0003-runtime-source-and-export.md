# ADR-0003：运行时数据库权威、可读导出长期可重建

- 状态：accepted
- 决定日期：2026-08-07
- 负责人：PersonalMemory maintainers

## 决定

SQLite 是本地运行时事务和查询的权威状态；用户拥有版本化、可读、带 manifest 与校验和的完整导出。FTS/向量索引未来必须可由规范化数据重建。当前 JSONL/Markdown 资产仅作为可读、可校验的用户资产保留；在导入与重建格式冻结前，它们不是迁移输入，也不构成完整事实源。

M4.7 明确了交付时点：上述“可重建”仍是长期架构方向，不是当前 MVP 能力。MVP 的跨安装迁移与灾难恢复只承诺已验证完整备份；可读导出不含检索索引、HMAC 密钥和完整运行时事实，不能导入、启动或替代备份。可读导入、冲突规则、schema 校验和索引重建 E2E 后置，完成前不得在状态页或使用文档中暗示可用。

## 原因与替代方案

数据库权威能提供事务、一致查询和迁移；可读导出保证可迁移与避免锁定。纯文件事实源更透明，但并发更新、删除和索引一致性复杂；纯数据库则难以人工审阅和长期迁移。

## 后果与复议触发

所有 schema 变更都必须带迁移和旧版本 fixture；导出/恢复需要闭环验证。若后续证明文件优先模型能在事务、性能、删除和冲突合并上达到同等可靠性，可通过新 ADR 替代。
