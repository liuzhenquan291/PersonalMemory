## 交付范围

- 建立 `apps/gateway`、`apps/web`、`packages/personal-memory` 和 `packages/mcp-server` npm workspace。
- 保持腾讯上游 `src/`、入口、脚本和 SDK 原位，不做目录级重构。
- 增加共享严格 TypeScript 配置和显式拓扑构建顺序。
- 增加机器可执行的依赖方向检查，禁止上游反向依赖产品层和产品层相对穿透上游 `src/`。
- 建立独立的 PersonalMemory schema version、migration ledger 和事务 runner；迁移采用声明式 SQL，禁止迁移代码取得数据库句柄或自行控制事务。
- 增加 v0 fixture，以及空库、幂等、旧数据保留、失败回滚、不可变 migration、高版本/ledger 与配置版本缺口拒绝、锁竞争重试和事务边界测试。

## 首轮检查发现并修复

1. npm `--workspaces` 不保证按依赖拓扑构建，Gateway/MCP 可能先于 core 而失败；根命令改为显式 core → gateway → MCP → Web。
2. 核心包测试最初继承根 Vitest 的 `src/**/*.test.ts` 范围，未发现 `tests/`；增加包级 Vitest 配置。
3. 消费包在无 core `dist` 时类型检查找不到声明；增加源码类型入口，构建仍使用产物 exports。
4. 首轮独立审查发现 migration ledger 缺口、边界检查绕过、`prepack` 耦合以及 format/lint 缺失；全部纳入修复和复审，未带病提交。
5. 最终复审发现迁移回调可提前 `COMMIT`，造成 schema 与账本不一致；迁移接口已收紧为 runner 执行的声明式 SQL，并在执行前拒绝事务控制语句，新增 DDL/数据不泄漏回归用例。
