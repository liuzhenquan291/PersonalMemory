# M5.7 版本化远程引导安装

- 状态：completed
- 执行日期：2026-08-27

## 范围

- 新增可由 `curl` 传给 POSIX shell 的 `bootstrap-personalmemory.sh`。
- 参数支持 `--repo`、`--version`、`--install-dir`、可重复 `--agent` 及 `--help`。
- MVP 仍依赖用户已有 Node.js/npm，暂不使用 Docker，也不在引导器内安装系统依赖。

## 安全与幂等边界

- `--version` 只接受规范化的 `personalmemory-vX.Y.Z`，并要求远端存在精确 tag。
- 引导器取得远端 tag 解引用后的提交；新克隆和已有检出的 HEAD 都必须与其一致，防止同名 tag 被重建后静默复用旧代码。
- 默认安装到独立于记忆数据根的版本目录；自定义目录必须是绝对路径。
- 新目录只浅克隆指定 tag，不跟随移动分支。
- 已有目录必须是同一仓库、包含同一 tag、HEAD 精确匹配且工作区干净；其他状态在运行正式安装器前拒绝。
- 安装目录和正式安装器不得是符号链接；Agent 组合在引导阶段提前校验，再传给版本内正式安装器。
