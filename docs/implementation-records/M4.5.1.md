## 官方资料核验

- Codex 官方手册聚合端点因 HTTP 403 不可用，按 `openai-docs` 技能流程改用官方 Codex Hooks 页面核验。
- Codex 当前支持 `UserPromptSubmit` 和 `Stop` command Hook；原生提供 session/turn、原始 prompt 和最终 assistant 文本，但 transcript 格式不是稳定接口，非托管 Hook 需按定义哈希由用户审阅信任。
- Claude Code 官方 Hook reference 提供等价事件；`prompt_id` 在 v2.1.196+ 可作为 turn 标识，Stop 应优先读取 `last_assistant_message`，因为 transcript 异步写入可能滞后；`agent_id` 可用于拒绝子 Agent。

## 交付范围

- 新增 `docs/architecture/AUTOMATIC_AGENT_MEMORY_HOOKS.md`，冻结事件映射、原始 turn 配对、Gateway-only、安全输出、授权 revision、服务端策略、模型授权分离、安装信任和验收矩阵。
- 新增 `packages/personal-memory/src/hook-contract.ts`，以 Zod 冻结两个客户端的 recall/capture 请求和结果，并提供确定性 JSON Schema manifest。
- 公共契约要求显式声明 `subagent=false`，并拒绝子 Agent 事件、其他 Agent 标识、transcript 路径、模型外联同意或客户端配置；召回固定最多 5 条/4,000 字符/1,000 token/1 秒，捕获固定为一条原始 user 加一条最终 assistant。
- 结果明确区分 recall 的 recalled/skipped/degraded，以及 capture 的 captured/duplicate/queued/skipped/conflict；只有可重试的 Gateway 可用性错误能进入 outbox。
- 反复影响后续实现的事件配对、transcript 降级、客户端信任与公共预算已同步写入 `docs/PROJECT_RULES.md`。
