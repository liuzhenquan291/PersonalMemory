# M5.6 可选多 Agent 安装

- 状态：completed
- 执行日期：2026-08-27

## 范围

- `install-personalmemory.sh` 原样转发安装参数。
- `--agent` 可重复指定 `codex`、`claude-code`，重复值去重；同时支持 `all` 与 `none`。
- 无参数时通过当前 `PATH` 自动探测受支持的 Agent；没有检测到时仍安装 PersonalMemory，但不写入 Agent Hook。
- 重复安装可以调整已选 Agent，且只添加或移除 PersonalMemory 管理的 Hook，不修改用户自有配置。
- 远程 `curl + git` 一行引导器涉及发布地址、版本选择与下载校验，不在本步骤实现，继续作为独立发布工程任务。

## 实现

- 新增独立参数解析与自动探测模块，并以单元测试覆盖合法组合、去重、顺序、缺值、未知值和互斥组合。
- 产品安装回执持久化规范化后的 Agent 集合；旧回执缺少该字段时兼容为原有双 Agent 行为。
- Hook 安装回执升级并记录所选客户端；未选择客户端的异常配置不会阻塞安装或被改写。
- 安装运行中切换 Agent 时，先验证新运行时，再调整 Hook；产品回执写入失败则恢复原 Hook 选择。旧首事件健康回执只在产品回执成功后清理，避免失败或中断时丢失原健康证据。
- restart、backup/restore 后重启和 upgrade 均沿用已持久化的 Agent 选择。
- 用户指南和发布说明补充单 Agent、多 Agent、全部、不集成与自动探测示例。

## 验证

- `npm run verify` 全部通过。
- `npm run test:install`、Hook 安装/受管测试、生命周期测试、升级测试全部通过。
- `npm run format:check`、`npm run lint` 与 `npm run release:check` 通过；最终发布扫描覆盖 572 个候选源码文件。
- 根项目与 TypeScript SDK 使用官方 npm registry 审计均为 0 漏洞；本步骤未变更依赖。
- Standards 与 Spec 独立审查发现的切换时误读未选择 Codex 配置、过早清理健康回执问题均已修复；最终复审无遗留 P0/P1/P2。

## 结论

安装命令已支持明确选择一个或多个 Agent，也能在无参数时按本机环境自动选择。选择结果在后续生命周期操作中保持一致，重复安装可安全重配，并保留未受 PersonalMemory 管理的用户配置。
