# M5.3 备份、恢复和卸载

- 状态：completed
- 完成日期：2026-08-12
- 提交：本记录随功能提交；提交 SHA 在提交后任务报告中记录
- 实施范围：新增 `npm run lifecycle:product -- <status|stop|backup|restore|uninstall>`，把现有便携数据能力接入受管进程停止、备份校验、恢复后启动和卸载生命周期。
- 路径安全：回执必须是 `0600` 普通文件；状态/数据目录必须是分离的私有真实目录；拒绝根目录、符号链接、嵌套路径和回执扩大删除范围。
- 卸载语义：默认仅停止受管进程并删除状态目录，完整保留记忆数据；清除数据同时要求 `--purge-data` 与精确 `DELETE <绝对数据根>`，确认在任何停止或删除前校验。
- 自动验证：`npm run test:lifecycle` 覆盖状态查看、停止、备份校验与重启、备份失败重启、恢复顺序与失败重启、默认保留数据卸载、错误确认零副作用和精确目标清除。
- 验证证据：`npm run verify` 全部通过，包括格式、lint、边界、构建、类型、上游与产品测试、安装/升级/生命周期/数据测试、黄金链路和 TypeScript SDK 测试。
- 审查结论：按递归删除目标、确认时序、失败重启和凭据生命周期复查；修复停止后残留凭据导致安装器无法重启的 P1，改为严格校验并复用已有私有凭据。修复后无未解决 P0/P1/P2。
- 下一步依赖：M5.4 发布候选验证覆盖真实 macOS/Linux 安装矩阵、跨安装恢复、卸载端口/配置状态和发布扫描。
