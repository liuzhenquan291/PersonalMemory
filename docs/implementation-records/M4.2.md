# M4.2 实现 PersonalMemory MCP Server

- 状态：completed
- 日期：2026-08-12
- 基线：`7e037ad`
- 契约版本：`1.0.0`

## 交付范围

- 使用官方 TypeScript MCP SDK 实现 stdio Server，注册 M4.1 冻结的五个工具，并同时返回结构化结果与兼容文本结果。
- 增加只允许带鉴权 loopback Gateway 的客户端和启动预检；MCP 不直接依赖 Gateway workspace、数据库、数据目录或上游内核。
- 将搜索、精确读取、单轮捕获、L1 反馈和遗忘预览映射到版本化 Gateway API，继续复用既有审核、治理、预算、外联确认和级联删除业务门禁。
- 为搜索增加短期、一次性、绑定请求的服务端游标；为 Gateway 响应、工具并发、跨页读取、stdio 输入和删除交接设置资源上限。
- 增加独立删除 handoff：MCP 只得到计数和引用，浏览器 session 才能读取内部预览；模型不能取得删除 token、确认短语、登记副本路径或执行接口。

## 审查结论

- MCP 进程没有任意文件、路径、SQL、整库导出、HTTP/SSE 或破坏性删除能力；授权和业务规则保留在 Gateway。
- stdout、结构化错误和 stderr 均不包含 token、正文、搜索词、内部路径或底层错误；记忆正文始终保留不可信数据标记。
- Web handoff 的服务端读取端点已建立且拒绝 Bearer；真实客户端如何引导用户打开 Web、全新配置保护和卸载恢复属于 M4.3 验收范围。
- 当前只证明官方测试客户端与协议运行时互操作，不把它宣称为真实 Agent 客户端验收或 M4 退出门完成。
