## 交付范围

- 以 `loadConfig()` 建立安全默认值、配置文件对象和环境变量的单一合并入口；未知键 fail closed。
- Gateway 默认 loopback；非 loopback 必须同时启用认证并从环境变量加载 token。
- 默认关闭模型访问和遥测；无密钥时安全返回配置引导状态，不隐式外联。
- 支持 `local` 与 `openai-compatible` provider；远程地址要求 HTTPS、无 URL 凭据、显式 origin allowlist 和环境变量密钥。
- `SecretValue` 保证字符串化和 JSON 序列化脱敏；配置文件 schema 禁止密钥字段。
- 提供外联披露结构，供后续配置引导展示 provider、目标 origin 和发送字段。
- 建立 macOS/Linux 默认数据目录和初始化器；拒绝根目录、既有文件、符号链接路径及权限不私有的既有目录，新目录使用 `0700`。
