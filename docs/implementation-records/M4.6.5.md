# M4.6.5 产品化采集策略、敏感规则与保留期策略

状态：review

## 范围

- 产品 schema v11 增加版本化采集策略账本，默认允许已另行授权的本地捕获，同时默认启用凭据、支付卡号和中国居民身份证号三类敏感阻断。
- 认证 Gateway API 提供当前策略、追加式审计历史与 expected revision 更新；支持全局暂停、按 Codex/Claude Code、规范化绝对工作目录树和 `agent_lifecycle` 来源排除。
- 策略 revision 更新同步推进 Hook authorization revision 与 policy revision，使旧前台请求和旧 outbox 条目不能沿用过期策略。
- 敏感内容检查位于 Hook 幂等账本和本地 L0 sink 之前；凭据覆盖常见标签、Bearer 和私钥头，支付卡号要求 Luhn 校验；命中时整轮跳过，不记录正文、命中值或工作目录。
- L0/L1 保留期分别记录为 1–3650 天或无限期，并通过同一认证 API 对用户可见。

## 明确非目标

- 不改变模型外联授权、Hook 生命周期授权或默认双关闭语义。
- 不增加团队、远程来源、自定义正则、敏感内容脱敏后继续保存或 L2/L3 编辑。
- 本步骤不直接执行到期物理删除。L0/L1 还关联向量/FTS、派生资产、导出和备份；自动清理必须作为后续独立变更接入既有受保护清理器，并重跑 M3.4 删除与恢复后不复活矩阵。
- Web 设置页可复用本步骤 API，但普通用户 Web/CLI 边界仍归 M4.7，不在本步骤扩展页面导航。
