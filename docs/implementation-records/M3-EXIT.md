# M3 可信记忆治理退出验收

- 状态：completed
- 日期：2026-08-11
- 覆盖步骤：M3.1–M3.4

## 退出结论

M3 退出门已通过。错误记忆可以先被隔离审核，再由用户修改、拒绝、设置有效期、建立冲突或替代关系；所有高影响操作进入不含正文的本地审计。对于需要不可逆清理的 L1，产品能够预览并验证来源、索引、可读副本、精确派生内容和登记导出/备份的级联删除，同时用 tombstone 阻止重建索引后的同 ID 复活。

“完整删除”严格限定为 [ADR 0005](../adr/0005-verifiable-privacy-erasure.md) 定义的受控范围。未知复制品和无法证明来源的语义派生内容会在确认界面明确披露，不以“未发现”冒充全设备不存在。

## 退出证据

- 审核：L1 默认 pending，只有 approved 进入召回；修改后接受保持上游写入先于审核落账。
- 治理：冲突暂停双方召回，替代无环且可撤销，有效期在召回前执行。
- 追溯：审计采用 HMAC 引用和严格详情白名单，可读导出不携带 HMAC 密钥。
- 删除：完整级联、部分失败重试、取消、受管备份删除、残留扫描及 tombstone 防复活均有自动化测试。
- 质量：M3.4 完成时全仓 `npm run verify` 和 Playwright 7 项通过，无未解决 P0/P1。

## 后续依赖

M4 从通用 MCP 工具契约开始，把已验证的搜索、读取、捕获、反馈和遗忘语义提供给真实 Agent 客户端。M5 继续完成一条命令安装、升级回滚、跨安装恢复、卸载和发布候选门禁；在 M4–M5 完成前，产品仍不宣称 MVP 已交付。
