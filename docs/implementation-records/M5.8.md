# M5.8 同事件 Hook 安全共存

- 状态：completed
- 执行日期：2026-08-27

## 问题

首次通过远程引导器安装 Codex 与 Claude Code 时，本机 Claude Code 已有 usage-tracking `Stop` Hook。旧安装器把同事件中的任何其他条目视为冲突，虽然没有覆盖用户配置，但无法完成双 Agent 安装。

## 实现

- 安装在事件数组末尾追加 PersonalMemory 受管定义，不替换已有数组。
- 健康和回执校验允许其他条目存在，但 PersonalMemory 摘要必须精确匹配一项。
- 定义升级先按旧回执摘要精确移除旧项，再追加新项，防止残留两个版本。
- Agent 切换和卸载只移除摘要匹配的受管项；删除后事件数组仍有用户 Hook 时予以保留。
- PersonalMemory 条目缺失、被编辑或重复时拒绝继续，维持管理范围 fail closed。

## 验证

- fixture 在 Claude Code `Stop` 中预装 usage-tracking 条目，验证安装后两项共存。
- 验证重复安装、Agent 集合切换、旧回执升级、定义升级、状态读取和卸载均保留 usage-tracking。
- 验证被修改或重复的 PersonalMemory 定义继续被拒绝。
- `npm run verify` 全部通过；Hook managed 14 项、安装 17 项、生命周期 14 项和升级 8 项均通过。
