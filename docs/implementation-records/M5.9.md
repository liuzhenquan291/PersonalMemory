# M5.9 可配置本地服务端口

- 状态：completed
- 执行日期：2026-08-27

## 问题

首次本机安装时默认 PersonalMemory Gateway 端口 `8787` 已被用户的 Python uvicorn 服务占用。安装参数只支持 Agent，无法在保留该服务的前提下完成安装。

## 实现

- 正式安装器新增 `--upstream-port`、`--gateway-port`、`--web-port`。
- curl 引导器提供相同参数并传给固定 tag 内的正式安装器。
- 三项参数只接受互不相同的 1–65535 整数，默认仍为 `8420`、`8787`、`4173`。
- 首次安装将实际 URL 写入私有回执，现有生命周期和升级流程继续沿用。
- 运行中的安装收到与回执不一致的显式端口时拒绝，要求先停止后重装。

## 验证

- 参数测试覆盖自定义 Gateway/Web 端口、缺值、非数字、越界、重复参数和端口重叠。
- 引导器 fixture 验证自定义 Gateway 端口传递。
- 安装运行时测试验证运行中显式更换 Gateway 端口被拒绝。
- `npm run verify` 全部通过；安装参数与运行时门禁共 19 项通过，生命周期 14 项、升级 8 项及 Hook managed 14 项通过。
