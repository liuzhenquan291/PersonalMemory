## 审查修正

- `memory.generated` 在上游缺少精确生成回调时只按“首次观察到”幂等记录，避免伪造生成时间。
- 记忆 ID 不直接进入审计表或响应；接口只返回 HMAC 前 16 位用于视觉区分，查询时在本地重新计算完整 HMAC。
- 详情只接受固定字段，任何 `content`、`query`、`reason` 等未列入白名单的字段都会拒绝写入。
- 可读导出不携带 HMAC 密钥，避免脱敏引用在离线文件中变成可枚举的稳定身份映射。

## 已知边界

- 写入时清理超过 365 天的事件，不提供用户自定义保留期界面；保留策略配置属于后续生命周期管理。
- 事件账本记录产品层已观察或执行的操作，不反向推断导入前或其他上游客户端产生的完整历史。
- M3.3 不提供彻底擦除；审计、导出和备份中的残留将在 M3.4/M5.3 的级联删除与生命周期验证中继续处理。
