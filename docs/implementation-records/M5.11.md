## 0.1.3 候选修复与复验

### 发布核验发现的问题

1. 备份/恢复成功或失败后的自动重启未传回执端口；新增四项回归在旧码失败，修复后通过。
2. 独立审查发现 HTTP 80 在 URL 规范化后端口为空；统一 `readManagedPorts` 保留 HTTP 默认端口，并在生命周期停服务前拒绝非法端口/非本地 URL。安装重复执行、备份恢复和升级复用同一解析。
3. 真实隔离安装的备份误探测默认端口上的其他实例，报“upstream Gateway is still running”；数据操作现使用回执中的上游端口，升级前备份和失败回滚也使用本安装的地址。
4. 升级重启同样补齐原端口传递；早期 version 1 缺失 URL 的回执沿用默认值，version 2/3 缺失或异常 URL 拒绝。
