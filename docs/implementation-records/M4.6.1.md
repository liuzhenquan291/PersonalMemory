# M4.6.1 统一模型配置与权威出站门禁

- 状态：review
- 日期：2026-08-21
- 基线：22e606c

## 边界

- PersonalMemory 受管安装显式设置上游 `TDAI_LLM_ENABLED`，不再让上游依据继承环境中的地址或密钥自行决定是否外联。
- 模型关闭时，启动器在创建上游进程前移除 `TDAI_LLM_*` 和 `MEMORY_TENCENTDB_LLM_*` 模型地址、密钥、模型及相关参数；无效或旧配置不能绕过产品门禁。
- 受管上游 Gateway 的通用 `StandaloneLLMRunner` 在构造模型 provider 或发送请求前执行最终门禁；该 Gateway 内直接创建的 offload 模型客户端在关闭时不创建。
- 上游独立运行保持兼容默认值；只有 PersonalMemory 受管启动强制使用产品派生的显式状态。
- 旧 OpenClaw 插件 `src/offload/index.ts` 的本地/后端 offload 客户端不被受管上游 Gateway 导入，属于独立上游兼容入口，不在本步骤的 PersonalMemory 进程和模型配置边界内。
- 本步骤不启用生产 Hook capture sink，不实现模型配置界面、版本化外联同意或发送字段披露，也不宣称完成全部遥测和第三方外联验证。
