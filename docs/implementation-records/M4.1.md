# M4.1 冻结 MCP 工具契约

- 状态：completed
- 日期：2026-08-12
- 基线：`d7d5b3f`
- 契约版本：`1.0.0`

## 交付范围

- 冻结 `personalmemory_search`、`personalmemory_read`、`personalmemory_capture`、`personalmemory_feedback` 和 `personalmemory_prepare_forget` 五个带产品前缀的最小工具。
- 以 Zod 作为输入、输出和错误 schema 的事实源，并提供确定性的 JSON Schema manifest；本步不提前引入 MCP SDK 或服务器运行时。
- 搜索实施条数、字符、token、时间和分页上限；L1 搜索结果必须已批准且只返回来源计数，精确读取最多披露 20 个来源 ID。
- 所有记忆正文明确标为不可信数据；错误码采用有界白名单，不包含正文、搜索词、内部路径、SQL 或底层错误。
- MCP 不暴露删除执行能力；遗忘工具只生成不可授权删除的 Web 交接引用，不能接受确认短语或报告删除完成。

## 检查与审查门

- [x] 契约测试覆盖稳定工具清单、严格 JSON Schema、超时、分页、上下文预算和游标一致性。
- [x] 提示注入 fixture 保持为不可信正文，来源 ID 只允许在精确读取中有界披露。
- [x] 捕获只接受一轮有序交换；反馈要求显式动作和乐观审核版本。
- [x] 删除绕过测试证明 MCP 输入没有确认字段，输出只能声明未执行破坏性动作。
- [x] 完整仓库质量门禁和依赖审计在提交前执行，结果记录在任务报告或 CI 中。

## 审查结论

- 工具集没有任意 SQL、文件读取、整库导出或破坏性删除接口；搜索不返回总库规模，避免把分页变成默认整库枚举。
- annotations 仅作为客户端提示，真实授权继续由 M4.2 的 Bearer、Gateway 业务门禁和服务端状态保证。
- 删除 handoff 不得复用 M3.4 内部执行 token；Web 必须重新加载范围并执行既有双确认和精确短语。
- 本步只冻结协议语义。进程权限、stdio 帧、断连、并发、关闭和真实客户端互操作分别留在 M4.2–M4.4 验证。
