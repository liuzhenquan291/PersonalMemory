# M5.1 一条命令安装器

- 状态：completed
- 完成日期：2026-08-12
- 提交：本记录随功能提交；提交 SHA 在提交后任务报告中记录
- 实施范围：新增 `npm run install:product`，覆盖 macOS/Linux 与 Node 版本检查、缺失时基于锁文件获取依赖、产品构建、私有运行目录和认证凭据、本机 Gateway/Web 后台启动、双健康检查、受管回执、重复安装验证和失败清理。
- 安全默认：只监听 loopback；模型与遥测关闭；随机认证 token 仅写入 `0600` 文件，不进入命令参数、回执或成功输出；端口检查发生在数据写入前；失败不删除既有记忆数据。
- 自动验证：`npm run test:install` 覆盖支持矩阵、Node 下限、macOS/Linux 默认目录、依赖已存在的断网路径、端口占用前置失败、私有权限、凭据不进入回执、双服务启动和健康失败清理。
- 验证证据：`npm run verify` 全部通过，包括格式、lint、边界、构建、类型、上游与产品测试、真实开发服务测试、安装器测试、数据 CLI、客户端配置、黄金链路和 TypeScript SDK 测试。当前受限环境的安装器单测使用隔离替身；真实干净环境安装矩阵保留到 M5.4 发布候选验证。
- 已知限制：M5.1 是源码仓库安装，不包含签名发行包；停止、修复、卸载和清除数据命令属于 M5.3。残缺/停止回执会 fail closed 并要求人工检查，不自动删除或覆盖。
- 审查结论：按安装流程、凭据、进程、网络和失败路径逐项复查；修复自定义 Gateway 端口未传给 Web preview 代理的问题后，无未解决 P0/P1/P2。
- 下一步依赖：M5.2 复用安装回执和既有 schema migration runner，增加版本检测、升级前备份、健康验证与回滚。
