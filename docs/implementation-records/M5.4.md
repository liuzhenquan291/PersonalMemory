# M5.4 发布候选验证

- 状态：completed
- 检查日期：2026-08-12
- 已验证环境：macOS 14.5 arm64；Docker Desktop 29.7.2 的 Linux arm64（官方 `node:22.22.1-bookworm-slim`）；Node.js 22.22.1、npm 10.9.4。Linux x64 与 macOS x64 尚未实测。
- 全量质量：M5.4 最终候选的 `npm run verify` 全部通过；黄金链路曾出现一次异步等待超时，随后单独复跑及多轮完整门禁均通过。该历史事件未复现，但仍纳入后续长期运行观察项。
- 依赖扫描：使用 `https://registry.npmjs.org` 执行根项目和 TypeScript SDK `npm audit --json`，两者均为 0 个 info/low/moderate/high/critical 漏洞。默认 `npmmirror` 不实现 audit endpoint，不能把其 404 当作审计结果。
- 许可证与秘密扫描：`npm run release:check` 验证上游 MIT 条款、package license、产品生命周期入口、loopback/模型/遥测安全默认值，并扫描 Git 跟踪文件和未跟踪候选文件的私钥、GitHub token 和 OpenAI 风格密钥模式；最终候选扫描通过，无 Git 的 Linux 精简镜像使用安全文件遍历回退并通过。
- 性能证据：既有黄金链路对启动、健康和搜索设定 15 秒、1 秒和 2 秒上限并通过；100 样本召回基线见 `docs/architecture/BUDGETED_RECALL.md`。Linux 全新容器从依赖安装到非降级首次召回在 15 分钟内完成；正式 RC 仍需用发布分发物记录精确计时。
- 生命周期与故障注入：安装、升级和生命周期自动化覆盖端口占用、启动健康失败、空间不足、迁移中断、备份/恢复失败、错误清除确认和安全重启；升级/恢复失败不伪报成功。
- Linux 干净环境：从只读源码复制到全新容器，删除所有依赖和构建产物后执行根项目与 TypeScript SDK `npm ci`、`npm run verify` 和发布扫描。验证暴露并修复了 macOS 生成的锁文件遗漏 Linux 原生 Rolldown、Lightning CSS、sqlite-vec、Jieba 和 esbuild 包的问题；修复后完整 `npm run verify` 通过，包括 100 样本 SQLite 检索、产品测试、黄金链路和 SDK 测试。
- Linux 实际生命周期：首次验证发现安装器只启动管理 Gateway（8787）和 Web（4173），导致 L0/L1 均为 `UPSTREAM_UNAVAILABLE`。现已把核心 Gateway（8420）纳入回执版本 2、重复安装、停止、升级、备份/恢复和卸载，并把一次非降级 L0/L1 召回加入安装成功条件。全新容器复验通过真实安装、非降级召回、重复安装、状态检查和默认卸载；三个进程均停止且数据保留。旧回执版本 1 仍可由升级/卸载路径安全读取。把数据根放在共享可写的 `/tmp` 下会按安全设计拒绝启动。
- 支持矩阵限制：Linux arm64 已完成干净构建、全量测试和实际生命周期；macOS arm64 已完成本机全量测试。macOS/Linux 的 arm64/x64 共 20 个必需原生包均已锁定并加入发布检查，但 Linux x64 与 macOS x64 尚无对应架构实测，不能宣称已验证。
- 正式分发物：采用 `PersonalMemory-0.1.1-source.tar.gz` + 独立 SHA-256 文件，不复用根项目的上游 npm 插件包。包内包含固定顶层目录、一条命令安装入口、上游 LICENSE、第三方依赖清单和机器可读发布清单，排除 `.git`、依赖缓存、构建输出、日志、密钥、用户数据和 `release/` 自身。包体积约 2.9 MiB；连续两次构建摘要一致，最终摘要以同批生成的 `.sha256` 文件为准。
- 分发物 Linux 验收：全新容器仅挂载压缩包和校验文件，校验、解包和 `./install-personalmemory.sh` 成功；从命令开始到非降级首次召回 89 秒。重复安装、备份及校验、清除数据卸载、重新安装、跨安装恢复、恢复后非降级召回和默认保留数据卸载全部通过。
- 分发物 macOS 验收：在用户主目录的私有临时目录中仅使用压缩包和校验文件，首次非降级召回 26 秒，重复安装通过；随后 60 秒执行 30 轮核心 Gateway、产品 Gateway、Web 和非降级召回联合探测，全部成功。默认卸载后三个进程停止且数据保留。公共可写的 `/private/tmp` 数据根会被安全检查拒绝，属于预期行为。
- 已知环境事件：补充长运行验证曾两次在依赖安装阶段遇到 npm 官方仓库 `ECONNRESET`/长时间无响应；产品服务尚未启动，按外部网络事件记录，不计为产品长运行失败。部分 npm 缓存的 `--offline` 安装按设计因未缓存传递包而 fail closed；项目不承诺部分缓存等同完整离线依赖镜像。
- 已知限制：首个发布清单只声明实测的 macOS arm64 和 Linux arm64；macOS x64 与 Linux x64 虽已锁定原生依赖，但在对应架构实测前不列为支持平台。MVP 仍是源码分发，需要用户预装 Node.js 22.19.0 以上与 npm。
- 结论：M5.4 和 M5 退出门通过。发布候选仅在本地生成，不移动 `main`，不发布或推送。
