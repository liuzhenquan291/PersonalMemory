# M4.6.4 版本化 Hook 生命周期授权

状态：completed

## 范围

- 产品 schema v10 增加版本化 Hook 授权账本；自动召回与自动本地捕获独立启停，首次安装和新安装身份均双关闭。
- 认证 Gateway API 分别固定披露召回/捕获的数据、处理时机、用途、目的地、预算、fail-open 和撤销效果，以 expected authorization revision 防止陈旧覆盖，并支持原子双关闭撤销。
- 安装身份由私有 Hook secret 的 SHA-256 摘要前缀派生，不暴露 secret；跨安装恢复自动追加双关闭 revision，不阻塞数据恢复。
- 生产 Gateway 直接读取账本作为 Hook 授权权威状态；受管 worker 在维护和 outbox flush 前同步服务端 revision，身份不匹配或同步失败均 fail closed。
- 非目标：Agent/项目/来源采集排除、敏感内容规则、L0/L1 保留期、Web 设置界面和模型外联授权。
