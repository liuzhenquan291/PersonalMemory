# M4.6.3 生产 Hook 本地 L0 capture sink

状态：completed

## 范围

- 生产 Gateway 使用独立 `vectors.db` 连接承载 Hook 幂等账本与本地 L0 sink。
- 上游 Gateway 先完成 health/schema 初始化；产品只 preflight L0 必需列，不创建或迁移上游表。产品自有 Hook 表使用独立 version=1 migration ledger。
- sink 只同步插入契约允许的一对原始 user/assistant L0 元数据；稳定记录 ID 由幂等键和角色单向派生。
- 幂等账本与 L0 行共享一个 `BEGIN IMMEDIATE` 事务，写入失败整体回滚。
- sink 不调用上游 `/capture`、embedding、L1–L3 提炼或网络客户端；未授权模型继续由 M4.6.1/M4.6.2 的受管环境和最终 Runner 门禁禁用。
- 非目标：开启默认 Hook 授权、Web 授权入口、采集策略、敏感信息规则和保留期设置。
