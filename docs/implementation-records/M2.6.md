# M2.6 导出、备份和恢复

- 状态：completed
- 日期：2026-08-12
- 基线：`5d9a434`

## 交付范围

- JSON/Markdown 可读导出覆盖 L0–L3 原始资产、来源字段和 PersonalMemory 状态/tombstone。
- 本地 SQLite 统一数据根备份包含显式资产 manifest、schema 版本、大小和逐文件 SHA-256。
- 恢复先验证包与 SQLite 完整性，再同文件系统原子切换，并保留恢复前数据根作为回退点。
- Gateway 运行 marker 阻止不一致热备份和运行中恢复；崩溃遗留 marker 可安全识别并清理。
- 命令行额外检查 loopback 上游健康状态，上游仍运行或状态无法可靠判定时 fail closed。
- 提供 `data:export`、`data:backup`、`data:verify`、`data:restore` 四个根命令。

## 边界

- M2.6 只支持统一数据根的本地 SQLite；远程 TCVDB 与拆分数据根明确拒绝。
- 配置、环境密钥、日志、历史备份和导出物不进入备份；出现未分类根资产时 fail closed。
- 导出、备份、恢复前必须停止 Gateway；生成物包含敏感正文，应用外复制后的权限由用户负责。
- 恢复前回退目录不会自动删除，避免不可恢复覆盖；其保留和安全销毁在 M5.3 完善。
