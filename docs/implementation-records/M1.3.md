## 交付范围

- 建立 Hono `/api/v1` 外观、健康/版本/配置状态、统一错误 envelope 和 request ID。
- 建立严格 Zod 请求契约，只映射 capture、recall、memory/conversation search 和 session end，不复制上游业务逻辑。
- 建立 Bearer 与 loopback 浏览器 session + CSRF 信任模型；非 loopback 不签发浏览器 session。
- 增加精确 CORS、流式请求体上限、上游超时、全局基础限流、安全响应头和结构化脱敏日志。
- 建立 credential-free loopback 上游客户端、编译期路由 allowlist、10 MiB 响应上限和不使用环境代理的 `node:http` 直连。
- 增加 Node Server 启停、端口占用恢复和重复关闭生命周期。
