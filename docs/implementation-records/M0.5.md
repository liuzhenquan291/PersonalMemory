## 已识别的产品化缺口

1. 当前非 loopback 无认证只警告，MVP 应拒绝启动。
2. 当前 API Key 可为空，loopback 同机进程仍可调用；产品层需要自动生成本地凭证。
3. 配置文件解析失败会静默回退，产品入口必须给出可操作错误。
4. 当前 L0/L1 删除不处理 JSONL、派生层、备份和日志，不能称为彻底删除。
5. 当前备份工具不是完整库备份，恢复前清目标目录的行为需要产品层事务保护。
6. 默认文件日志路径 `/data/log/` 不适合作为产品路径，M1.2 需统一到受控数据根并收紧内容策略。
7. 支持平台目前只实测 macOS arm64；Linux/amd64 仍待验证。
8. 空 LLM Key 不会阻止 standalone runner 尝试调用默认 OpenAI 公网地址；在 M1.2 修复并完成隔离验证前，默认零外联属于阻断目标而非当前能力。
