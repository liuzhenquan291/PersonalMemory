# M4.6.2 版本化模型授权与受管生命周期映射

状态：completed

## 范围

- 新增认证保护的模型授权查询、授权和撤销 API；授权精确绑定披露版本、provider、目标 origin 和三类发送字段。
- 新增 schema v9 授权账本，只保存披露元数据、哈希、revision 和时间，不保存模型密钥。
- 私有 `gateway.env` 成为受管模型配置的单一来源；启用模型时模型名必填。
- 安装生命周期只在当前披露已授权时映射上游 `TDAI_LLM_*`，并移除继承模型配置和代理变量；未授权、撤销、账本缺失或读取失败均 fail closed。
- 新增受管 `restart` 生命周期命令以应用授权变化；模型 HTTP 客户端禁止自动跟随重定向，防止请求越出已授权 origin。
- 非目标：Web 配置表单、生产 Hook capture sink、全部遥测外联验证。
