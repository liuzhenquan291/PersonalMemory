## 3. 供应链与安全检查

### 阻断问题

#### P1：上游脚本含疑似硬编码凭据

`scripts/start-offload-local.sh` 存在一个外观类似真实 LLM API Key 的非空默认值。未尝试验证该凭据是否有效，也不在文档中保存或复述其内容。

处理要求：

- 合并暂停态必须将默认值改为空值或安全占位符；
- 不执行该脚本；
- 把上游公开历史视为可能已暴露该值，不能将其作为任何环境的有效凭据；
- 建议上游所有者轮换/吊销对应凭据；PersonalMemory 无法替上游完成轮换。

#### P1：没有 lockfile，依赖解析不可复现

根项目和 TypeScript SDK 均使用 semver 范围但未提交 lockfile。本次安装分别解析出 556 个根依赖包和 45 个 SDK 依赖包；未来同一 tag 可能安装出不同结果。

处理要求：M0.3 合并暂停态生成并审查适用于 PersonalMemory 的锁文件，CI 使用确定性安装；依赖升级必须独立验证。

#### P1：当前解析依赖存在高危安全公告

使用 npm 官方安全公告端点检查本次解析快照：

- 根依赖：33 项，含 3 个 high、30 个 moderate、0 个 critical；主要涉及 OpenTelemetry、AI SDK 依赖链和间接 `undici`。
- TypeScript SDK 开发依赖：5 项，含 1 个 critical、1 个 high、3 个 moderate；主要来自旧版 Vitest/Vite 开发工具链。

处理要求：在 M0.3 合并暂停态升级或裁剪依赖并重新构建、测试；创建 merge commit 前必须清零未接受的 high/critical，或取得用户对具体公告的明确接受。

#### P2：公开 release 缺少核心可运行测试

根项目的两套 Vitest 配置均无法发现测试。合并前可记录基线，合并后不得在缺少核心回归保护的情况下开始大面积重构。

处理要求：M0.3 在合并暂停态增加至少一组可由根项目 `npm test` 发现的核心 smoke 测试，并保持根 build、TypeScript SDK 32 项测试和 Python SDK 34 项测试通过；M0.4 再建立隔离黄金链路，M1.1 建立统一 verify。
