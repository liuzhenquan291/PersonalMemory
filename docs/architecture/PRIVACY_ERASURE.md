# 可验证级联删除

> API：`POST /api/v1/privacy-deletions/{preview|:token/cancel|:token/execute}`

## 删除矩阵

| 类别 | 定位依据 | 执行动作 | 完成验证 |
| --- | --- | --- | --- |
| L0 来源 | L1 `source_message_ids` | 每批最多 100 个精确删除 | 重新分页查询 ID 不存在 |
| L1 事实与索引 | L1 ID | 上游原子删除 SQLite、FTS、向量项 | L1 全量分页查询不再返回 |
| L0 可读副本 | `conversations/*.jsonl` 消息 ID | fail-closed 解析后原子重写 | JSONL 残留行数为 0 |
| L1 可读副本 | `records/*.jsonl` 记忆 ID | fail-closed 解析后原子重写 | JSONL 残留行数为 0 |
| L2/L3 派生内容 | 正文完整精确匹配 | 用明确删除占位符替换并整文件写回 | 重读全部文件后精确出现次数为 0 |
| 产品治理元数据 | L1 ID | 删除审核、有效期和关系；保留无理由 tombstone | tombstone 状态为 `deleted` |
| 登记导出/备份 | 产品账本绝对路径 | 校验类型和路径后整件删除 | 每个登记路径均不存在 |
| 审计与删除凭据 | HMAC 引用或随机盐摘要 | 保留非正文证明 | 检查无正文、理由和原始来源内容 |

缓存和临时文件没有独立事实资产：SQLite 语句/页面缓存只存在于进程内，JSONL 临时文件使用同目录随机文件并在原子 rename 后消失；删除预览仅保存在内存且十分钟过期。任何新增持久缓存或临时目录都必须先加入该矩阵，未分类资产不得被静默忽略。

## 交互与失败语义

预览由服务端重新读取目标，而不是信任浏览器提交的正文或来源 ID。它返回每类数量、登记副本精确路径、过期时间、三条能力边界和要求输入的确认短语。浏览器必须同时取得两项复选确认，不能只靠一个通用“我知道了”。

执行开始前再次比较计划专用摘要；目标在预览后变化时返回 409，要求重新预览。执行开始后不接受取消，因为部分回滚会恢复已要求删除的正文。每一步独立记录成功或失败并继续最大化清理；任何步骤失败或残留非零都返回 207 `partial`，同一 token 在一小时内可以继续幂等重试。完整成功返回 200 并立即销毁内存计划，过期计划也从内存移除。

## 路径与副本安全

- 只处理产品账本登记的绝对路径，路径必须位于活动数据根之外。
- 路径链任何位置出现符号链接即停止；不会跟随链接删除目标。
- 备份必须含 `personalmemory-backup` manifest；JSON/Markdown 导出必须带 PersonalMemory 格式标记。
- 明文导出和备份整件删除，不做可能破坏可恢复性的选择性重写。
- 用户移动或复制文件后，旧登记路径无法代表新位置；产品明确要求用户自行确认，但不把确认计入自动残留扫描。

## 重启、重建与恢复

完成或部分删除都会先保留无正文、无理由的 L1 tombstone。Gateway 重启和上游重建索引后，浏览与召回仍先应用 tombstone，因此同 ID 数据不能复活。登记备份在级联删除时整件移除；主动保留并恢复的未登记旧备份属于用户明确创建的新外部副本，恢复后 tombstone 仍需随产品数据库一并恢复，否则不能声明延续原删除状态。

M3.4 的“complete”是受控范围完成，不是全磁盘取证保证；该边界由 [ADR 0005](../adr/0005-verifiable-privacy-erasure.md) 固定。
