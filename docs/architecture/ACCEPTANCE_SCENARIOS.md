# 产品化 MVP 端到端验收场景

M0 只冻结场景、fixture 和退出标准；场景自动化从 M2 开始。所有场景必须在隔离数据目录和默认无外网环境运行。

| ID     | 场景                                  | Fixture                                                                              | 自动化步骤                                                                                | 退出标准                                                                                                                                                                     |
| ------ | ------------------------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| E2E-01 | 首次启动与安全默认                    | 独立空 HOME、无配置/密钥、拦截所有非 loopback 连接；不复用黄金记忆数据               | M1.2/M1.4/M1.5（功能依赖），M2.1（fixture 边界落地），M5.1（安装矩阵）                    | 一条命令启动到引导页；只监听 loopback；零外联；重跑不覆盖数据；健康状态解释缺失配置                                                                                          |
| E2E-02 | 捕获、提炼、检索、来源与 MCP 可移植性 | 固定中英文多轮会话、确定性本地 mock LLM、提示注入记忆、两个 MCP 客户端 fixture       | M2.1/M2.2/M2.3/M2.4、M4.2–M4.4；Codex 与 Claude Code 已完成同一五工具真实会话             | L0 写入后生成 L1；搜索命中；同一 L1 可追溯到确切 L0；召回遵守条数和 token 预算；正文注入不被执行；重启结果一致；两个 MCP 客户端的召回结果、来源、预算与权限边界一致          |
| E2E-03 | 人工纠错、失效与受控删除              | 含错误偏好、重复事实和 L2/L3 派生物的数据集                                          | M2.5、M3.2、M3.3                                                                          | 修改保留来源与审计；失效内容不再召回；普通删除准确报告已删除范围和仍保留副本，不静默级联                                                                                     |
| E2E-04 | 导出、备份、恢复与升级                | 多 schema 版本 fixture、损坏备份、磁盘中断注入                                       | M2.6、M5.2、M5.3                                                                          | 导出可读且完整；校验失败不覆盖现库；跨安装恢复结果等价；重复迁移幂等；失败可回滚                                                                                             |
| E2E-05 | 隐私级联删除与安全卸载                | 同一事实分布于 L0/L1/L2/L3、索引、缓存、备份与日志引用                               | M3.4 已覆盖级联删除；M5.3、M5.4 补安全卸载                                                | 预览列出目标；确认后活动数据和登记副本不可查询/恢复；重建索引不复活；未知复制品边界明确；卸载默认保留数据，清数据需二次确认                                                  |
| E2E-06 | 自动 Agent 召回与捕获                 | Codex/Claude Code 隔离 HOME、自然提示、pending/approved/注入 fixture、重复和失败事件 | M4.5 已完成契约、实现和隔离双客户端 Hook fixture；M5.5 重跑真实分发物与可用真实客户端矩阵 | 无需“搜索/保存”口令；只注入 approved 有效记忆；成功主轮成对捕获；失败/中断/子 Agent/注入不回写；重复事件幂等；故障 fail-open 或进入有界 outbox；授权、策略、信任和卸载可验证 |

通用失败条件：连接公网、写出隔离数据根、输出密钥/完整正文到日志、依赖固定等待时间、留下进程或端口、测试只验证 HTTP 200 而不验证持久化结果。
