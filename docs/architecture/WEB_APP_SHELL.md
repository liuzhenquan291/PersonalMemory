# PersonalMemory Web 应用壳

M1.4 建立单用户个人记忆管理入口。Web 只消费 PersonalMemory Gateway 的版本化 `/api/v1`，不直接调用腾讯上游，也不复制 L0–L3、检索或提炼逻辑。

## 页面与状态

- `/memories` 是默认入口，首版提供个人记忆语义、搜索占位和可行动的空状态；真实列表、筛选与编辑在 M2 接入。
- `/settings` 提供本地 Gateway、记忆访问保护和模型连接的只读状态；Agent MCP 配置在后续步骤接入。
- 路由错误由顶层 error boundary 隔离；查询层必须分别呈现加载、失败和成功状态，失败信息不得暴露响应正文或本机路径。
- 界面只使用“你的记忆、来源、连接、设置”等个人词汇，不引入团队、成员、组织、租户或工作区概念。

## 前端边界

- React Router 负责页面边界，TanStack Query 负责远程状态；页面不得自行维护并行的请求缓存。
- 开发服务器只监听 `127.0.0.1:17177`，`/api` 默认代理到 PersonalMemory Gateway `127.0.0.1:17175`，不得指向上游核心 Gateway `17173`；显式覆盖开发端口时代理同步变化。M1.5 统一管理开发入口和生命周期，生产部署仍留待发布阶段。
- Gateway 状态请求使用相对路径且只读取公开布尔状态；浏览器 session、CSRF 和记忆 API 接入时必须继续遵循 `GATEWAY_BOUNDARY.md`。
- Web 构建产物是可再生资产，不保存用户记忆，也不成为运行时事实源。

## 可访问性与视觉规则

- 所有主要路径必须可用键盘完成，提供跳过导航链接和可见焦点，页面结构使用 landmark 与语义标题。
- 动效必须尊重 `prefers-reduced-motion`；移动端从双栏切换为顶部导航，不隐藏主要功能。
- 视觉采用“个人记忆索引台”方向：深靛蓝、雾灰蓝、纸白和信号青绿；“记忆线索轨道”是唯一标志性元素，其余装饰服从信息层级。
- 空状态说明下一步，错误状态说明可执行的恢复动作，加载状态提供明确反馈，不以空白页面代替状态。
